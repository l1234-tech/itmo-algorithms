## Теория

Для единой навигации по лекциям, конспектам, PDF и Jupyter Notebook используй [каталог теории](./docs/theory/README.md). В каждой теме также есть собственный README с материалами и ссылками.

## Как устроен раздел

В тематических папках используются следующие каталоги и файлы:

- `теория/` — лекции, конспекты, PDF и Jupyter Notebook;
- `прак/` — практические реализации и упражнения;
- `дз/` — домашние задания, решения и сохранённые условия;
- `contest.md` — ссылка на контест, если он предусмотрен;
- `README.md` — обзор темы, ссылки на материалы и заметки о сложностях алгоритмов.

В старых заданиях имена файлов и папок могут отличаться. Существующие пути сохранены, чтобы не ломать ссылки и привычный порядок сдачи работ.

## Языки и запуск

Основной язык решений — Python. В отдельных заданиях также используется C++.

Для запуска Python-файла перейди в каталог задачи и выполни:

```bash
python 1.py
```

Перед запуском проверь формат ввода и вывода в условии. Некоторые старые решения читают данные из `input.txt`, а другие используют стандартный ввод; запускать их нужно с учётом этого различия.

## Стандарт оформления задач

По мере обновления материалов описание задачи должно содержать:

1. условие или ссылку на него;
2. идею алгоритма;
3. ссылку на файл решения;
4. временную и пространственную сложность;
5. тесты и важные граничные случаи.

Шаблоны лежат в [docs/templates](./docs/templates/).

## Назначение

Репозиторий предназначен для систематизации материалов курса, повторения теории и практики алгоритмов и структур данных. Это учебный сборник: наличие файла с решением само по себе не означает, что оно прошло полную автоматическую проверку.
