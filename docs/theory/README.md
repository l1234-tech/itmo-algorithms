## Как пользоваться

1. Открой README нужной темы — там собраны материалы и ссылки.
2. Используй Markdown-файлы для быстрого перехода, Jupyter Notebook — для изучения примеров и кода.
3. PDF и внешние лекции открываются по исходным ссылкам; они оставлены без изменений.

> Репозиторий — учебный конспект. Проверяй формулировки и граничные случаи на примерах из курса.
