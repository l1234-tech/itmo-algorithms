## Ключевые идеи

- Базовый случай должен завершать вызовы.
- Рекурсивный переход должен приближать задачу к базовому случаю.
- Оценивай не только время, но и глубину стека вызовов.
- Сравнивай наивную рекурсию с мемоизацией и итеративными решениями.
