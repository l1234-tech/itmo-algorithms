## Основные идеи

### 1. Хеш-функция и коллизии

Хеш-функция отображает ключ в целое число, которое затем преобразуется в индекс массива корзин. Разные ключи могут попасть в одну корзину — это называется коллизией. Поэтому при поиске нужно сравнивать исходные ключи, а не только их хеши.

### 2. Подсчёт частот

Словарь позволяет хранить количество появлений каждого ключа. Ожидаемая амортизированная сложность операций поиска и обновления — (O(1)), хотя в худшем случае она может ухудшаться из-за коллизий.

### 3. Скользящее окно и мультимножество

При сдвиге окна достаточно уменьшить частоту элемента, который вышел, и увеличить частоту вошедшего. Ключ удаляется из словаря, когда его частота становится нулевой. Так можно поддерживать число различных значений без повторного пересчёта окна.

### 4. Префиксные суммы и хеширование

Пусть (P_i) — сумма первых (i) элементов. Подотрезок имеет сумму (s), если для текущей префиксной суммы (P) ранее встречалась сумма (P-s). Словарь частот префиксных сумм позволяет посчитать такие подотрезки за ожидаемое (O(n)).

### 5. Реализация хеш-таблицы

В задаче 4 реализована таблица с отдельными цепочками для разрешения коллизий. В коде есть операции `put`, `get`, `delete`, получение размера и увеличение числа корзин с перехешированием элементов.

## Сложность

| Операция / подход | Ожидаемое время | Примечание |
|---|---:|---|
| Поиск, вставка, удаление в хеш-таблице | (O(1)) | При хорошем распределении хешей |
| Обработка массива со словарём частот | (O(n)) | Каждая операция словаря ожидаемо (O(1)) |
| Подсчёт подотрезков через префиксные суммы | (O(n)) | Каждая префиксная сумма обрабатывается один раз |
| Перехеширование таблицы | (O(n)) | Выполняется при изменении ёмкости; стоимость амортизируется |

## Запуск решений

В каждой папке задания лежат исходный файл, входные данные `input.txt` и изображения условия. Обрати внимание: у задач 1–3 путь к `input.txt` задан относительно корня репозитория, а задача 4 открывает `input.txt` относительно текущего каталога.

Запуск задач 1–3 из корня репозитория:

```bash
python "хеш таблицы/дз/1 задача/1.py"
python "хеш таблицы/дз/2 задача/2.py"
python "хеш таблицы/дз/3 задача/3.py"
```

Запуск задачи 4 из её каталога:

```bash
cd "хеш таблицы/дз/4 задача"
python 4.py
```

## Что проверить при решении задач

- пустой ввод и минимальный размер массива;
- повторяющиеся ключи и нулевые частоты;
- коллизии и удаление элемента из цепочки;
- отрицательные числа в задачах с префиксными суммами;
- окна длины (1) и (n);
- корректность обновления частот при удалении ключа;
- перехеширование и сохранение всех ключей при увеличении ёмкости.

> Это учебный раздел. Условия задач сохранены рядом с решениями; наличие решения не означает, что оно прошло полную автоматическую проверку.
